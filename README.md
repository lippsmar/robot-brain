# robot-brain

Gehirn eines kleinen KI-Roboters: Claude Code (Planung, Code, Skills), OpenClaw (agentische Ausführung) und Memory Core (Gedächtnis L0 bis L5), gesteuert über einen Microcontroller-Hub mit Sensorik, LTE/SIM, Mail, BLE und Not-Aus.

- Projektregeln für Claude Code: [CLAUDE.md](CLAUDE.md)
- Gedächtnis-Regelwerk: [memory/SYSTEM_PROMPT.md](memory/SYSTEM_PROMPT.md)
- Skills: [skills/INDEX.md](skills/INDEX.md)
- Entscheidungen: [memory/decisions/](memory/decisions/)

Notion ist das führende Gedächtnis des Projekts (Seite „Robot Brain“). Dieses Repo hält die Dateien, die Claude Code und der Roboter direkt nutzen.
